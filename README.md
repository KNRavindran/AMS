Apartment management system(AMS) is a project created for management and collection of maintenance money
for common area electricity, common maintenance charges from residents of appartment.
The money collected from residents are used for managing expenses incured by the apartment like Security salary, garbage collectors, common
electricity charge payments.

Using AMS, itemized invoices can be generated for each units in the apparment based on the unit size in square feet, utilized electricity
based on electricity meter readings that are on taken monthly basis and eneterd in AMS.
